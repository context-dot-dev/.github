# Context.dev

Context.dev is a web scraping API for AI agents and LLMs. One API key scrapes any URL to clean markdown, crawls whole sites, searches the web, takes screenshots and extracts structured JSON. Proxies, JavaScript rendering and anti-bot handling are included.

[Website](https://context.dev) · [Docs](https://docs.context.dev)
